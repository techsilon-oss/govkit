# Security

**Report a vulnerability by email to oss@techsilon.com, not in a public issue.** Include what you found, how to reproduce it, and the govkit version. You'll get an acknowledgement, and a fix or an assessment, as soon as it has been looked at.

Supported: the latest release only. Fixes ship as a new release; nothing is backported.

govkit's scripts run on your machine as you. For what the plugin itself reads, writes and connects to, see "What govkit does on your machine" in the README.
